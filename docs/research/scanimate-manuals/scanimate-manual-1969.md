# Scanimate Operator Manual (Computer Image Corp., Denver, ca. Dec 1969 - Apr 1970) - design notes for Rasterwarp

Citation format: [fNNN/pX] = scan file pNNN.png / printed page X (printed numbering is file-4 for f009-f023, file-3 from f026 on; f038-f063 are schematic sheets with no printed numbers).
Quotes are short; everything else paraphrased. "(inference)" marks my own deduction, not manual text.

Big picture: this is an early (1969-70) Scanimate with a TWO-KEYFRAME model, not a patch-bay model. The operator sets an INITIAL image (position/size/rotation) and a FINAL image, plus up to 3 oscillators (H, V, depth) that wobble the position/size, and a single linear ANIMATION RAMP crossfades initial -> final over an adjustable time. The image can be split into up to 5 independently animated horizontal "sections" (commutator). The "monitor" is a 5-inch magnetic-deflection CRT whose 600-line / 48 Hz raster is *re-deflected*; a film camera shoots the CRT.

---------------------------------------------------------------
## 1. ANIMATION OVER TIME / TRANSITIONS
---------------------------------------------------------------
- Core concept [f020/p15 4-4, 4-6; f019]: operator composes an INITIAL image (any position, size, shape, rotation) and a FINAL image, then tells the machine to animate; Scanimate "automatically creates" the in-between raster sequence. Effects listed: zooms, lateral/vertical translations, rotations, size increase/decrease, "plasticizing". Entire image or up to FIVE sections can be animated separately.
- Rate/shape statement [f019/p15 4-6; f022/p17 4-9]: transition rate is variable; "linear rate of motion, or a sine wave rate, or a combination" may be chosen; also "specified non-linear rate". In hardware the ONLY built-in transition curve is a linear ramp; sine-like motion comes from the oscillators (see 3).
- ANIMATION RAMP GENERATOR [f029/p26 4-54; f023/p19-20 4-19]: an integrator producing a 10 V to 0 V (spec text: "-10 to 0 volts") linear run-out; duration is "continuously variable" and "extending up to some seconds", set by RATE-A or RATE-B pot. Integrator is held shorted by an FET until INITIAL-FINAL switch goes to FINAL (reset = INITIAL). Integrator output is clipped (4 V zener limit) in one branch to avoid overload [f029 4-55].
- Mixing law [f023/p19-20 4-18, 4-19]: each channel's deflection = position signal + raster signal. A multiplier (variable attenuator) driven by the ramp crossfades INITIAL position (strong at start) to FINAL position (strong at end). So pos(t) = (1-r)*P_initial + r*P_final with r linear 0->1 (inference from description). Raster (size) is crossfaded the same way through the depth/size channel. Final image "without oscillation".
- Controls (Table 3-1) [f012/p8, f013/p9]:
  - INITIAL-FINAL switch (S2): normally INITIAL; throwing to FINAL starts the sequence. Operator-triggered, no timer/auto-start.
  - Rate Select switch (S3) A/B: two rate pots (RATE-A R1, RATE-B R2). Switching A<->B DURING the animation is allowed and changes the sequence speed on the fly [f018/p14 3-39] (=> piecewise-linear speed, a crude speed ramp / "two-speed" move).
  - RAMP-BYPASS switch (S4): RAMP = normal ramp generator. BYPASS = the selected RATE pot is wired to the depth circuit directly instead of the ramp (i.e. manual/hand-controlled transition) [f012/p8 item 3].
  - Ramp Select switch (S8) per oscillator: MAX TO MIN, MIN TO MAX, CONSTANT [f013/p9 item 29]. This sets whether the oscillator's amplitude contribution fades out (max->min, uses the 10->0 V ramp), fades in (min->max, inverted ramp), or stays constant (10 V bias) over the transition [f026/p23 4-20].
  - SEQUENCE-FRAME switch (S11) and Sync switch (S12 LEFT/RIGHT/OFF): oscillator phase-lock. FRAME = oscillator restarts every monitor frame (48 Hz); SEQUENCE = oscillator restarts when the animation sequence starts; OFF = free running. Sync switch picks the side from which oscillation begins [f013/p9 items 31-32; f018/p14 3-33/3-34]. With several oscillators running, the combined effect is best judged with Sync OFF.
  - Operator rehearsal workflow [f018/p14 3-36]: set Rate switch to A, tweak RATE-A while repeatedly flipping INITIAL-FINAL; same for B. i.e. live scrub-by-repeat to tune duration.
  - Section LENGTH CONTROLs on commutator also affect timing structure (see 6) but are spatial, not temporal.
- Film procedure [f018/p14 3-38..3-40]: set camera focus/aperture/frame rate, start movie camera, "After two seconds" throw INITIAL-FINAL to FINAL; stop camera at end of desired time. So the sequence start is manually cued ~2 s into film (lead-in hold of the initial image; hold at final image is whatever time remains before camera stops). Reset = back to INITIAL.
- Sync of ramps to frames [f027/p24 4-27, f031/p28 4-63; f018 3-33]: the 48 Hz vertical reset is gated so it is locked to the film camera shutter (camera-run detector charges a cap from shutter pulses; vertical reset "occurs only once during each camera run"). A SYNCH AND SIMULATOR card [f032/p29 4-66; f040 SM-125] senses shutter with a photo-FET (~50 ms pulse) or simulates it with a front-panel switch S2 (CAMERA / SIMULATE) when no camera runs. (Inference: this means the monitor free-runs 48 Hz; when a camera is running, it re-locks so each film frame sees whole raster frames.)
- Oscillator-based time motion: oscillators run in real time (Hz, see 3), they are NOT tied to the ramp except through Ramp Select amplitude shaping and the sync switches.
- No key positions/presets beyond two: the "A/B or preset" concept is exactly INITIAL vs FINAL (separate pots for each: Initial/Final Horizontal, Vertical, Depth, Rotation on main panel; and per-section on commutator) [f012/p8 items 8-13, f013/p9 items 27-28; f014/p10 Table 3-2]. Final is selected simply by the INITIAL-FINAL switch for monitoring, so the operator can flip between the two looks live.
- Setup order [f016/p12-f017/p13]: power on; test pattern; focus scanner; adjust sections; set FINAL image; set INITIAL image; set oscillators; set ramp rates.
- Table 3-3 / calibration [f016/p12]: with SECTION SELECT = 5 down, all commutator pots and initial H/V/depth and final H/V at 0 V (+/-0.5 V); FINAL DEPTH reads -10.0 V (+/-0.5). So depth/size ramps have a built-in -10 V offset convention at final.
- Overall effect on intensity during motion: image-speed term is added to brightness (see 2/6).

## 2. RASTER / SCANLINES
---------------------------------------------------------------
- Format [f026/p23 4-21, 4-24; f027/p24 4-27; f023/p19-20 4-18; f029? sync]: 600-line frame, 48 frames per second (called "48 hz frame rate"), horizontal line rate 28.8 kHz. NOT interlaced (single 48 Hz vertical reset; 28,800/48 = 600). Master clock 86.4 kHz, phase-locked to 60 Hz power line (Raysistor-tuned oscillator; /3 = 28.8 kHz; /1440 = 60 Hz ref; /1800 = 48 Hz) [f027/p24 4-27; f030/p27 4-58..4-62]. Drift: if clock drifts, derived 60 Hz drifts and the phase detector pulls it back.
- TV mode [f031/p28, f033/p30 4-78]: vertical reset 48 Hz "for film" or 60 Hz "for television"; line rate ~28.35 kHz noted on SM-105A for TV sync [f039]. "Raster characteristics, such as number of lines, lines per second, and interlacing" differ between film and TV; SM-105A is a TV-sync variant [f032/p29 4-65]. (The older SM-105 sheet [f041] labels a 19.2 kHz node; the text says 28.8 kHz.)
- Camera/monitor are the same XY raster: a TV scanner (1-inch vidicon, ~900 V supply) scans the artwork; the monitor CRT's sweeps are driven by the same reset pulses, so scan and display are in sync. The monitor sweep is then *modified* by the Scanimate computer (size, position, rotation) so the 600 lines are redistributed over a different area/orientation [f019/p15 4-4,4-5; f020/p16 Fig 4-1; f026/p23 4-24]. Display "using the same number of scans" - so enlarging the picture spreads the same 600 lines over a larger area (visible line gaps), shrinking packs them (brighter, solid) (inference from 4-5; brightness compensation in manual confirms it, see 6).
- Raster generation [f033/p30 4-75..4-77; f044 SM-103]: two integrators with timed reset; horizontal reset at 28.8 kHz makes a sawtooth (amplitude = SIZE bias); vertical raster ramp is slower (48 Hz) with "lower gain". Position signal sets where the sawtooth starts. Output is a straight ramp (integrator, so linear; ramps are the only raster shape).
- Raster rotation / non-orthogonal axes [f026/p23 4-22; f025/p21-22 Fig 4-4]: raster axes themselves are rotated by theta. For raster of size x,y: new x extent = x cos(theta) - y sin(theta); new y = y cos(theta) + x sin(theta). Done with FOUR raster generators (two per axis) multiplied by cos/sin from a sine-cosine calculator (integrator-comparator driven by the rotation bias) [f025; f026]. Lines therefore rotate and shear with the image (the raster itself is rotated, not the picture afterwards). Initial/final rotation signals are mixed by the animation ramp. "Axes ... may be other than orthogonal thus tilting or rotating the image" [f021/p17 4-8].
- Flip/reverse [f021/p17 4-8]: raster can start at bottom and sweep upward (image inverted) or right-to-left (reversed), via negative size.
- Sections [f021/p17 4-7; f022/p18 Fig 4-2; f027/p24 4-28..4-30; f033-f034/p30-31 4-80..4-86]: the 600 lines (one frame) can be split time-wise into up to 5 consecutive rasters, each with its own size/position/rotation. "Total number of raster lines in all rasters must equal" the standard raster. Section lengths are set by variable-delay one-shots (LENGTH CONTROL pots) triggered from vertical reset; adjust #5 first ... #2 last; section 1 gets the remaining time. Monitor is blanked between sections (two-horizontal-line wide blank at end of each section) but the TV scanner is not [f032-f033/p29-30 4-73, f034/p31 4-85]. SECTION CAUTION/alarm light if section 1 not in progress at vertical reset (i.e. lengths exceed frame) [f034/p31 4-86]. Note (ambiguity): p13 says sections are numbered top-of-artwork down, while 4-28/4-29 describe the shift register running 5->4->3->2->1 in time, ending with the vertical reset.
- Rasters may lie partly or fully outside the visible CRT face / "TV-safe area" [f020/p16 Fig 4-1B; f022/p18]. SCANIMATE raster area is a square much bigger than the round monitor CRT face; the standard raster area is a smaller rectangle inside it. Items may fly in from outside the face.
- Monitor CRT: 5-inch tube per schematic title "BLANKING AMPLIFIER ... 5" MONITOR" [f060 SM-123]; magnetic focus coil + magnetic deflection yoke (current-driven yoke amps, +/-48 V supplies, LINEARITY and OFFSET pots) [f035/p32 f036/p33 4-115..4-118; f058]. Anode ~20 kV, +1000 V (+500 option) and +100 V rails [f037/p34 4-124..4-125; f061]. Beam shut off during retrace by a ~36 V p-p blanking pulse on the cathode; BRIGHTNESS pot sets the DC reference [f036/p33 4-121; f060].
- Setup rules for beam/focus [f016/p12 3-9..3-18]: scanner focus: lens focus, then monitor FOCUS control; video from scanner set to 1 V p-p (lens F2.8 or F4); fill the "grid plate" raster area with SCANIMATE SIZE controls. "Obtain sharpest image possible" with FOCUS. INTENSITY set so an undeflected trace has only enough brightness "to expose film without a halo effect". CAUTION: excess brightness burns phosphor. (=> glow/halo is an artifact the operators avoided; a software glow should be modest.)
- Edge softness/bandwidth: camera video preamp response stated as dc to 40 MHz (as printed) with HF peaking amplifiers; low-frequency and HF roll-off trims (R23, C10) [f034/p31 4-92]; video gate FET AGC; DC clamp/restore diode in monitor video amp [f036/p33 4-120]. (Printed "40 mhz" is surprisingly high for a vidicon system; probably real preamp bandwidth, actual picture softness comes from vidicon, focus, and deflection amp inductive load. Inference.)
- Vidicon scan details [f034/p31 4-97..4-100; f047-f049]: camera uses separate X/Y ramp generators (SM-113), X ramp short and Y ramp long, yoke drivers with SKEW and OFFSET, vidicon blanking & protection board (beam blanked on retrace; also if either sweep fails), ALIGN #1/#2, magnetic focus, electrostatic focus, BEAM and TARGET adjusts, and a SHADING COMP / CORRECTION OUT input (f047). Two cameras (Camera 1, 2) with a switcher can feed the system [f008/p3-4 Fig 2-1].
- X/Y SIZE of the vidicon scan itself is also variable (X SIZE, Y SIZE pots) to match the artwork [f026/p23 4-24].

## 3. DEFLECTION / SIGNAL GENERATORS
---------------------------------------------------------------
- Three channel oscillators: HORIZONTAL, VERTICAL, DEPTH (all identical SM-107 boards) [f012/p8 index list; f032/p29 4-67]. Each has ON-OFF switch, FREQUENCY pot, AMPLITUDE pot, EXT IN jack (signal into the channel when switch OFF), OUTPUT jack, Ramp Select (S8), Sync (S12), SEQUENCE-FRAME (S11), phase-lock sync input.
- Frequency range [f026/p23 4-20]: "approximately 0.025 to 500 hertz" (plus a SLOW/FAST switch on the board [f042 SM-107]). Amplitude adjustable. Combination of freq, amplitude and ramp type "can give an infinite array of oscillatory motions".
- Waveform [f032/p29 4-68..4-71; f042]: integrator-based triangle/sawtooth generator (bias +/-, comparators flip polarity; frequency set by bias; SLOPE SYMMETRY pot), then a 5-step zener-diode shaper (3.3, 5.1, 6.8, 8.2, 9.1 V breakpoints on feedback of an amplifier) turns it into a "roughly sinusoidal" output. So: piecewise-approximated sine, small distortions; asymmetric slope possible with SLOPE SYMMETRY (inference: gives sawtooth-ish variants).
- Where oscillators enter [f026/p23 4-20, f024 -> f025 Fig 4-4]: oscillator output (after Ramp Select multiplier) is summed with the INITIAL position signal (horizontal osc -> X position, vertical osc -> Y position). Depth oscillator is summed with INITIAL depth to wobble SIZE. It is therefore a position (translation/size) wobble, applied before the rotation multipliers; it fades according to ramp select; and it is absent at FINAL (unless ramp select = CONSTANT).
  - Because the monitor beam position is displaced as a function of TIME while the 600 lines are being scanned, a horizontal oscillator at f Hz shifts successive lines sideways with phase advancing f/28800 cycle per line, i.e. f/48 cycles per frame height (500 Hz -> ~10 cycles up the picture; 48 Hz -> exactly 1; 2 Hz -> 1 cycle per 24 frames across the whole frame, a rigid slide). Vertical oscillator moves lines up/down by time within the frame - it stretches/compresses spacing (line bunching and gaps). Depth oscillator breathes size => size modulation of each line's sweep amplitude (inference from the signal flow; manual says oscillation effect is "oscillatory initial position signal").
  - Phase relation to frame: SEQUENCE-FRAME sync "FRAME" makes the wave stationary on screen; free running (OFF) lets it crawl.
- Position/size (Table 3-1/3-2) [f012-f014/p8-p10]: per-image (initial / final) HORIZONTAL, VERTICAL, DEPTH ("apparent depth (size)"), per-section on commutator; WIDTH and LENGTH (raster width and height of the displayed rect); overall channel GAIN H and V ("gain of horizontal channel"); AXIS H/V controls (axis about which the raster may rotate); FIELD (rotation degree about axis; FIELD switch NORM position in power-on list [f016/p12 3-8a]); ROTATION INITIAL/FINAL pots; EXT IN jacks W (J51) and L (J52) accept +10 to -10 V to add to WIDTH and LENGTH [f013/p9 item 26].
  - "Depth": 2D screen can show depth only as size [f026/p23 4-23]; the depth channel feeds a size ramp that sets the bias of all four raster generators. Final width/length depend on relation of initial and final depths; "A final image at greater depth than the initial image would be of lesser raster size" [f012/p8 note].
- Signal levels: +/-10 V (position, oscillators), size ramps -10..0 V, commutator pots +/-10 V (via +/-10 V zener refs) [f044 SM-102; f012; f016]. IC op-amps (MC1439/1739-family), FET switches (2N4342, MEM562/517), MC1595 multipliers; i.e. fast analog parts, 15 V rails.
- Deflection amp [f036/p33 4-115..4-118; f058 SM-122B]: voltage-to-current yoke driver, differential pair + complementary power stage, +/-48 V rails, 0.5 ohm sense, LINEARITY and OFFSET adjustment. Deflection linearity "frequency compensation" is mentioned (C14) - i.e. real yoke has limited speed (inference: fast ripples would round off).
- Output signals to console (Fig 2-1) [f008/p3-4]: signals named X SIZE, Y SIZE, X ANIM, Y ANIM, VERT RESET, X (horiz) RESET, HORIZ OUT, VERT OUT, INTENSITY, VIDEO IN, MONITOR BLANKING, CAMERA BLANKING, FILM CAMERA SHUTTER. "X ANIM"/"Y ANIM" = position-only signals (pre-rotation raster-free) used to compute image speed. HORIZ OUT / VERT OUT = final deflection to monitor.
- Named effect recipes: none given as recipes. Effects named in prose: zoom, translation, rotation, flip, "plasticizing" (= oscillatory distortion), enter from outside the viewing area, size change, tall/narrow or short/wide (aspect change), "tilting or rotating" non-orthogonal axes. Figure 4-2 example: sections A B C fly in from above the screen and settle at lower screen, growing from small to bigger lettering [f021/p17 4-7].

## 4. COLORIZING
---------------------------------------------------------------
- This 1969 manual is essentially MONOCHROME. No brightness-level-to-color mapping, no level keying, no level counts are described.
- Only color hooks:
  - A THREE-COLOR LIGHT BOX ("cricket box") is used on the Display Table when color animations are filmed; a single-source light box for monochrome [f006/p1 1-12]. i.e. color is produced by lighting the artwork with R/G/B in successive passes/exposures (inference) and filming color stock; not a CRT color process.
  - Commutator panel row labelled "R B G": per Table 3-2 [f014/p10 items 13]: "R and B controls: Not used on this model"; G control "Controls individual section intensity" (per-section brightness, i.e. a per-section gain on the video/intensity). Commutator wiring has RBG RED/BLUE/GREEN lines [f038 SMW-101] and the Intensity board has "Provisions for ... three color light box" [f032/p29 4-72].
  - Per-section intensity = the closest thing to level control.
- CRT video chain: positive/negative video inputs, GAIN, an intensity-compensation multiplier (MC1595) before the grid; output stage swings grid from about -34 V (blank) to +12 V [f061 SM-127; f036/p33 4-119..4-120].

## 5. RECORDING / OUTPUT
---------------------------------------------------------------
- Output = 16/35 mm type movie camera filming the monitor CRT; camera mounted on the Monitor Table [f006/p1 1-4, 1-10; f007 Fig 1-1]. Also "recorded on film or videotape" [f019/p15 4-4]. Monitor frame rate is 48 Hz for film, 60 Hz for TV [f033/p30 4-78]; film camera frame rate "according to manufacturer's manual" - not stated (inference: 24 fps film = 2 monitor frames/film frame).
- Shutter sync [f031/p28 4-63; f032/p29 4-66; f001 schematics f040]: camera shutter position fed back to sync generator (CAMERA SHUTTER POSITION), vertical reset is synchronized once per run, "to prevent filming the Camera Shutter Bar". Camera run detector with ~0.47 uF/16 uF timing caps. Photo-FET pickup (Chicago Miniature 715/6809 lamp) senses reflected light from the shutter.
- Video path to TV: monitor-side flyback blanking and composite sync ("TV CAMERA BLANKING"/"COMPOSITE SYNCH" outputs on SM-105/105A) for the TV version [f041; f039]; two cameras + video switcher (Viscount) on the video input table [f008].
- Quality: CRT intensity set low to avoid halo; focus; two-second lead-in; light box; scanner 1 V p-p video at f/2.8-f/4.
- Power/env: 115 V, 50-60 Hz, 20 A [f006/p1 Table 1-1].

## 6. OTHER AUTHENTICITY DETAILS
---------------------------------------------------------------
- INTENSITY COMPENSATOR (very relevant for glow/brightness in emulation) [f026/p23 4-25..4-26; f035/p32 4-109..4-114; f054-f057]:
  - Two compensations. (a) Area: compares the displayed area (from X size & Y size) to scanned area so the same total video energy shows over a smaller area would otherwise be brighter, over a larger area dimmer; compensator keeps "tonal scale true". Formula on diagram f054: output = 0.1|XsYs| + 0.01|Xs| + 0.01|Ys| (0..+10 V); text f035 writes the 1/area forms (log/antilog multiplier-adder: 0.1/(XsYs) + 0.01/Xs + 0.01/Ys with SIZE GAIN pot). I read it as: brightness ~ 1/(area) with small 1/|Xs|, 1/|Ys| terms that keep brightness finite when one dimension collapses to ~0 ("the multiplier is bypassed and the other signal maintains video intensity" [f027/p24]). (b) Speed: for fast-moving images the eye sees dimming, so an IMAGE SPEED signal sqrt((dXa/dt)^2 + (dYa/dt)^2) (differentiators + squarers + adder-rooter) is added so brightness rises with image velocity [f027/p24 4-26; f035/p32 4-111..4-113; f055; f056]. Square-root step is because "brightness of the CRT increases roughly with the square of the signal voltage" at grid [f035/p32 4-113] -> emulate CRT as gamma ~2 and compensate with sqrt.
  - INTENSITY pot (R21) on console adds into this (SCANIMATE INTENSITY CONTROL) [f013/p9 item 24; f055 J63].
- Interconnect: three units: SCANIMATE Console (computer chassis + commutator chassis), Monitor Table (monitor CRT, film camera, power, deflection amps), Display Table (TV scanner, light box, camera control electronics) [f006/p1 1-6..1-12; f007 Fig 1-1].
- Operator workflow / terminology: INITIAL image, FINAL image, animation sequence, ramp, RATE A/B, sections (numbered from top of artwork), LENGTH CONTROL, SECTION SELECT, raster, standard raster, grid-plate raster area, TV-safe area, light box, "cricket box", position/size/rotation/depth, FIELD, AXIS, commutator (a "five-position, fifteen-pole electronic switch" [f027/p24 4-28]), "animation aid" output [f008]. Section Caution light. Master clear at power-on.
- Commutator mechanics [f033-f034/p30-31 4-79..4-86; f044 SM-102; f038 SMW-101]: five identical panels (axis/intensity, rotation, size & sequence, initial position, final position), each 5 sections x 3 pots; FET gates select section n's pots into the shared channels during that section's time slice. Per-section pots: final H/V/depth, initial H/V/depth, width, length, final/initial rotation, G intensity ("sequence" and "commutator" rows not used on this model).
- Adjustment voltage convention (Table 3-3) +/-0.5 V tolerance [f016/p12]: tells us operator pots are centered 0 V = neutral (centered position, standard size ~ -10 V at final depth?).
- Imperfections / quirks to emulate: (a) 28.8 kHz line structure always present, line gaps when enlarged, line bunching/brightening when shrunk; (b) vidicon shading / lag / focus softness (shading comp input exists f047); (c) oscillator quasi-sine with zener-step distortion; (d) clock locked to AC line (stable, line-locked hum); (e) monitor blanked between sections (dark gaps between sections), (f) CRT phosphor + film halo; (g) deflection amp lag at high ripple frequencies; (h) intensity compensation not perfect (brightness leaks, "image speed" boost); (i) linear ramp only - everything moves with constant velocity in transition unless oscillators or a rate flip are used; (j) a section whose length exceeds frame triggers section alarm; (k) manual cue/hold at start (~2 s) means start of motion is operator-timed.
- Hardware sync gen detail [f027/p24 4-27; f030/p27]: 86.4 kHz -> 28.8 kHz horizontal reset one-shot, 48 Hz vertical reset one-shot; reset pulses drive both camera sweep and monitor raster ramps (SM-103 / SM-113). Flyback blanking is composite of the two.
- Pages with no design info: f001 cover, f002-f004 TOC/figs, f007 photo, f009-f011 connector panels, f063 etc. Power-supply sheets f049 (SMW-200), f061-f063 (HV, +5, +/-36 regulators) irrelevant to emulation beyond voltages noted above.

## EMULATION TAKEAWAYS (my synthesis)
---------------------------------------------------------------
1. Model transition as two parameter sets (initial, final) + one 0..1 ramp r(t) (linear by default, start on cue, duration up to several seconds, two selectable rates A/B switchable mid-run, optional bypass = manual hand control). pos/size/rot = lerp(initial, final, r) + oscillator*(ramp-select envelope: 1-r, r, or 1).
2. Oscillators: 3 (H, V, depth), 0.025-500 Hz, 5-segment pseudo-sine, amplitude pot, phase-lock modes FRAME (restart at each 48 Hz frame -> stationary ripple), SEQUENCE (restart at cue), FREE.
3. Raster: 600 lines, 48 Hz, 28.8 kHz line rate, no interlace; displacement applied as a function of beam time (line index within frame) => ripple appears as per-scanline offsets; size/rotation applied by scaling/rotating the raster basis (cos/sin multipliers), lines rotate with image; line gaps from oversizing; compensate brightness by 1/area plus image-speed boost (CRT gamma ~2).
4. Up to 5 stacked sections each with own initial/final transform, summing to <= 600 lines; blank between sections.
5. Monochrome base; color is added by per-section intensity and (for color film) separate R/G/B light-box passes; no luminance-level colorize described in this manual.
