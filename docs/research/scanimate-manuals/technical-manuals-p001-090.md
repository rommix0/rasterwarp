## 1. ANIMATION OVER TIME / TRANSITIONS  (richest content in this volume)

### Animation Aid (p035-p041, p047-p051): the "time" system
- Animation Aid is an add-on box expanding Scanimate (p035). Provides: mouth control from audio, sequential intensify of 2-5 sections with per-section frame count, 1-5 sequential ramp generators each adjustable for rate AND start time, linear or sine ramp shape selectable (p035).
- Sequential Intensity Generator (p037): intensifies ONE section and blanks all others; 2 to 5 section sequence selected by a front-panel rotary switch. A two-digit thumbwheel sets frames per section: X1 position reads 1-99 frames directly; X10 position reads 10-990 frames (p037). Start/stop toggle: sequence starts when thrown stop-to-start and cycles continuously until returned to stop (p037).
  - Worked example (p043): 5 sections, 47 frames each, X1 -> "first section should intensify for 2 seconds" (47 frames ~ 2 s at 24 fps; counter rule is count = N-1: they set 47 for 48 frames, and set 23 for a 24-frame/1-second cycle: "Set frame count to 23 (the 24th count is used to reset the counter)" p043-p044). So frame units are video frames; nominal 24 per second used in the examples (film-style rate), though NTSC is 30/60.
  - Sequence intensity voltages can be repurposed to jump a section instantly between two screen positions and back once a second (p043-p044): set frame count 23, patch C1 to two cherry-switch buses, set pots 2 and 3 for the displacement. If patched to INITIAL horiz/vert instead of FINAL, the back-and-forth gets multiplied out in final position (p044).
- Sequential Ramp Generator (p037-p038, p044-p051):
  - Each ramp has a manual/auto switch. Manual starts ramping at a rate set by that ramp's "rate" pot; auto holds it reset (p037-p038). All switches must be in auto for automatic runs (p038).
  - Scanimate's INITIAL/FINAL switch starts ramp #1. Ramp #2 starts automatically at a frame number set on a 3-digit thumbwheel ("start 2"); ramp 3 uses "start 3", etc. Ramps may start in any order and have independent rates (p038). Returning switch to FINAL resets ramps and frame counters (p038, p045).
  - Frame counter: 3-digit thumbwheels; on sequence-ramp timing generator card a 3-position switch: back = normal count, center = off (counter stopped), forward = X2 (doubles count): extends control span "from about 40 seconds to over 80 seconds" (p038-p039, p046-p047). 999 frames max -> roughly 40 s, which implies ~24-25 fps count basis (999/40). Center "off" lets each ramp be run independently, "good for setting up an animation" (p047).
  - Triangle or sine shape selectable per ramp (p038); Card #10/#11 (p032): each ramp has a "sinewave output" adjust pot and a "reset rate" pot (ramps #1-#5 plus a spare); i.e. the ramp is shaped through a sine-shaping stage (ease in/out) when sine is selected.
  - Initial-final-initial (A-B-A) operation (p047-p048): needs 2 ramps per section plus 2 summing amps; ramp 2 started late and subtracted from ramp 1 produces ramp-up, hold, ramp-down. Example: rate ~1 s each; "start 2" = 096 frames; image moves initial->final in 1 s, holds 3 s, moves back in 1 s (p048) -> 96 frames = 4 s => 24 frames per second basis confirmed.
  - Sequential multi-move example (p048-p051): single section, zoom from dot to <half screen at lower right, then left, then up, then back to dot using depth. Each ramp 1 s, hold 2 s per position: start 2 = 072, start 3 = 144, start 4 = 216 frames (i.e. 72 frames = 3 s -> 24 fps). Result: "start at a dot in center and zoom to lower right and hold for 2 seconds. Then it will move horizontally to the left and hold" (p050-p051).
  - Ramp outputs patch via cherry-switch to Scanimate's INITIAL/FINAL channels (horiz, vert, depth/size); final-position pots on Scanimate must be re-set whenever cherry pots (gain) change, because the ramp adds to the final position (p045, p049-p050).
  - Inverting a ramp requires a unity-gain inverting summing amp; one ramp can feed horiz AND vert to get 45 degree motion (p049-p051).
  - Motion directions: ramp 1 patched to final horiz moves image left to right; final vert moves bottom to top; manual switch back to auto snaps back "very fast" (p048) -- i.e. reset is near-instant, not a reverse ramp.
  - Depth: with ramp on final depth, "in the auto position the image will be small and in the manual position the image will be large" (p048).
  - "A triangle or sine shape may be selected" on all (p038, p040).
- Sequence mode on Scanimate: Z-channel PC board J6 has a toggle that disables Scanimate's own sequence ramp in favor of Animation Aid ramps (p046); function switch has "commutator" and "sequence control" positions; "sequence commutator pots" set zero volts in final (p046-p047).
- Low-frequency oscillators 3,4,5 (p039-p041): phase-lockable to "frame" or "sequence" (frame/sequence switch), and to top or bottom (top/bottom switch) = start at positive or negative peak; "sine/cosine" PC switch sets whether waveform starts at zero or at a peak when phase-locked; "fast/slow" PC switch: SLOW disables phase lock - oscillator stops running and ramps to a +/- extreme and stays there until the top/bottom switch is flipped, so each oscillator doubles as an extra linear/sine ramp generator (p040-p041). Osc 3 = cosine reference, osc 4 = sine slave, locked to same frequency (pot 4 disabled) (p040).
- High-frequency oscillators 1,2 are phase-locked per HORIZONTAL LINE (not per frame) so the whole raster is shaped identically each line (p039).
- Scanimate II card #8 "sequence ramp timing generator", #10/#11 sequential ramp generators, #6 sequential intensity (p032).
- Animation Controller "Card #25 Horizontal, vertical rate ramp generator" with H and V rate-ramp amplitude pots (p033): ramps whose slope is rate of line-by-line change (a ramp per horizontal line / per vertical line).
- Scanimate II Card #5 "Animation adder and differentiator": pots for Y/X multiplier zero and DC offset, Ys and Xs gain/offset (p006). Contents list also names "Animation Adder & Differentiator SM-134B" and "X Animation Differentiator, Intensity Comp SM-135" (p001): animation signals are summed and differentiated (differentiation compensates intensity for stretched lines).
- Scanimate II Card #6 Z channel: pots for "min-max sequence" and "max-min sequence" (p007) = sequence ramp endpoints; "electronic oscillator switch" (p007). Z animation multiplier zero point/offset.
- Electric Timer (p001, p059-p063): "Electric Timer" S-1 standard timer with Sonalert 2.9 kHz tone (p060), SM-140 control card with 40 V secondary transformer and a 9601 one-shot (p062-p063) - an audible/lit run timer for cueing takes, not an animation function per se.
- Section Control timing (p010-p011) also relevant to stepping: sections are by horizontal line counts, not frames.

### Colorizer transition (p022-p023): see heading 4; the "Transition" dual pot cross-fades two video sources (A/B) in the mixer (p022-p023). A knob-driven dissolve between camera video and colorized Y.

### Video mix/effects (p029): A, B, C bus mix and effects circuits with MIX, LAP (lap dissolve), WIPE, NORM, REV preview modes; KEY processing with SENS and ADJ controls; program/preview/monitor outputs. A bus/B bus/C bus video, 8 video inputs (J34-J41) with sync-or-non-sync designation, "system timing" block with inputs J21-J23 (VIDEO 1, VIDEO 2, non-sync). This is the post-Scanimate video switcher style for A/B transitions (mix, lap dissolve, wipe, key; normal/reverse).

## 2. RASTER / SCANLINES

- Section Control (p010-p011): raster is divided into up to 5 horizontal SECTIONS by line count. Front-panel thumbwheel switches give number of horizontal lines from vertical reset to the end of each section; sections run top to bottom, Section 1 at top. Each switch must be larger than the previous; Sections 1-4 set by switches, section 5 = remainder before the next vertical reset (p010). For a single section set the first control higher than lines in a vertical interval; to disable commutators set it to 0 (p010). A switch equal to or less than previous disables all later commutators from that one on (p011). "After each section ends, a section blanking pulse is generated which is 2 horizontal lines wide" (p011). Resolution is one horizontal line with "no problems with jitter" (p011) (implies earlier versions jittered).
- Raster is built by horizontal line counters (SM-104B counter with 7490 decade counters, 17-position rotary switch, BCD thumbwheel; 96 diodes = gating matrix) (p071-p072). So section boundaries are on exact line counts of the scan converter raster.
- Blanking Controller vertical segment control (p054): 4 sets of 3-digit thumbwheels = line number (0-999) that starts each segment, same as section control.
- Blanking Controller horizontal segment control: 20 variable one-shots each with a front pot; the first pot of each vertical segment starts at the left edge of the raster and moves right; minimum width is less than the horizontal blanking pulse, maximum longer than a line; segments chain (segment 2 starts when segment 1 ends) (p054). Inhibit/external/enable switch decides blank/unblank (p054, p053). Used to wipe on/off selected portions of the raster (p054). External inputs for sequential blanking pulses patch from animation controller (p053).
- Scanimate II Card #17 Intensity section (p008): pots set TOP, RIGHT, LEFT, BOTTOM limit points of the raster, and widths of horizontal and vertical blanking pulses. i.e. the raster has adjustable edges and adjustable blanking widths (overscan/active area).
- Scanimate II Card #15 Sync section (p008): pots set position of "shutter bar" in frame, and position of "scan converter bar" in frame (2 pots) -- the shutter bar/scan converter bar are the visible bars in the frame that the film/scan converter timing creates (pot R35 shutter bar; R28/R26 scan converter bar).
- Raster bending (p035, p042, p051): two HIGH-FREQUENCY oscillators (about 90 kHz max, p039) are provided for "raster bending"; locked to horizontal line so the entire raster is shaped. For maximum effect applied on initial or final vertical channel of the cherry switch (p051). Amplitude +/-10 V max via pot or external multiplier input (p039). Waveform triangle or sine (p039, p033). Mouth example (p042): upper lip = osc 1, lower lip = osc 2 (split raster into 2 sections), "a little less than one cycle of bending" per line; zero crossings of the bend must be at the lip ends or corners "will either part or cross" (p042) -> shows that raster bending moves line positions vertically per scan line position horizontally (a sine of horizontal position added to vertical deflection; since HF osc period is a fraction of a line).
- At 90 kHz max with a 15.7 kHz line rate: up to ~5.7 cycles of ripple per line.
- Artwork-to-scan: artwork camera is conformed to the artwork aspect ratio; this can lower the "1 volt of video" level, restored by computer size controls (p012).
- Edge fringing (p013): "finite time of the transition" of the scan converter beam going black -> lighter produces colored/intermediate fringes along VERTICAL edges. Fringe is dark edge against lighter color, increasing apparent sharpness; more noticeable with more levels. (bandwidth-limited edge response; horizontal bandwidth limit, no vertical equivalent.)
- Colorizer sync timing (p021): H drive delayed 1.5 us -> X-Y camera horizontal reset one-shot; V drive delayed .2 msec -> vertical reset one-shot; composite clamp = OR of H and V portions (p021). Timing source: "Type 140 NTSC Test Generator" supplies H drive, V drive and composite blanking as 0 V to negative pulses (p021).
- The system has a "Scan converter" (camera viewing a CRT; "scan converter bar", p008; "scan converter camera", p021) and an "X-Y monitor"; output of gray-level encoder video amp is "the video that goes to the X-Y monitor" (p019). So Scanimate flow: artwork camera -> deflection warp -> X-Y monitor (high-res CRT) -> scan converter camera -> NTSC/colorizer.
- Deflection amp (p004-p005): see heading 3.
- SM-144 "Synch card for T.V. Rates" and "50/60 Hz reference" SM-137 (p001, p084): sync generator can be set for TV rates; sync gen SM-105F uses phase comparator ICs (MC4044/4024) = PLL to line/field (p085-p086).

## 3. DEFLECTION / SIGNAL GENERATORS

### Signal flow / terminology
- Cards numbered in a nest; pots numbered back to front (p006, p032).
- Channels: "Horizontal channel" (card 13), "Vertical channel" (card 12), "Z channel" (card 6, intensity/depth), "Ramp generator" (card 10), "Signal rotation" (card 11), "Sync section" (15), "Intensity section" (17) (p006-p008). Each deflection channel has "depth multiplier", "mode multiplier", "sequence multiplier" each with a ZERO POINT and DC OFFSET trim (p008).
- Channels labelled X or Y (SM-101B), Z (SM-100B/C) with MC1595L analog multipliers (MC1595 = 4-quadrant multiplier) in parts lists (p079-p082), HA2-2515 op amps, Intersil 8007 op amps (p081, p069). Z channel card also uses LM302, LM393-type comparators (p079).
- Ramp generator SM-103A: horizontal and vertical ramps (raster ramps) with multiplier ICs MC1595; pots (card #10 p007): horizontal axis multiplier zero, horizontal size multiplier zero, horizontal size AND axis multiplier DC offset, vertical size and axis DC offset, vertical size multiplier zero, vertical axis multiplier zero (p007). => Size = ramp x gain multiplier; Axis (center) multiplier; "axis" is the point scaling/rotation pivot ("axis locate" p025).
- Rotation: Signal Rotation card #11 (SM-136B): 12 pots for vertical and horizontal sine/cosine multipliers zero and DC offset (p007) -> rotation is performed as a 2x2 matrix: H' = H*cos - V*sin, V' = H*sin + V*cos using multipliers; sine and cosine voltages supplied by Rotation Controller D/A (digital memory-lookup sine/cosine, p002, p027-p028). "Axis locate" switch holds a point fixed at pivot during axis-locate interval (p025-p026). Rotation rate switch X1/10x; rotation rate pot; direction reverse; step manually; "initial" storage register can load angle (p025-p027). Rotation zero cal: null sine/cosine multiplier feedthrough by pots (p025-p026) - "better the null, the less axis movement during rotation" (p026). Standard levels: sine and cosine peaks +/-10 V (20 V p-p) (p027-p028); "Set horiz & vert oscillators to 20 V p-p" (p025). Rotation sequence mode on section 1 (p025).
- Rotation Controller (p002, p027-p028): digital: memory address card, memory card (lookup table), D/A converter producing sine and cosine, rate clock, sequence control, control card (SCCS series). Monitors: "tpl on front panel goes low momentarily" marks 90 degree reference (p027): initial condition "sine = +max, cosine = zero" = 90 degrees. Sine and cosine gains calibrated so each swings 20 V p-p; sine offset adjusted for equal +/-10 V ("plus and minus values must be as close as possible; relative amplitude is not as important") (p028).
- Basic "oscillators" in Scanimate: horizontal animation oscillator, vertical animation oscillator, depth animation oscillator (Scanimate II cards 2,3,4): each with pots for positive/negative slope symmetry (R3), negative peak voltage (R2), positive peak voltage (R1) (p006) => each is a triangle-based oscillator with adjustable asymmetry and peak levels, shaped to sine (SM-107A has a zener-clamped break-point sine shaper: zeners 3.3, 5.1, 6.8, 8.2, 9.1, 10 V, p088-p089). "Set horiz & vert oscillators to 20 V p-p" (p025).
- Slaved Cosine Generator (AM-112A) (p030): oscillator No. 3 master; slave generates cosine; adjustments: waveform symmetry, rect-ramp, sq-wave, sq-ramp, sine shape; "Osc. No. 4 Amplitude pot ... MULT BAL for minimum oscillation" (p030). Internal waveforms: triangle -> rectified ramp, squared wave, square-ramp -> sine shaper.
- Animation Controller card list (p032-p034): cards 13/14 HIGH frequency animation oscillators (output multiplier DC offset and null, triangle neg/pos peak, triangle slope symmetry, "adjusts for best sinewave output"); cards 15/16/17 LOW frequency animation oscillators (same pots); card 18 audio preamp; 19/20/21 dual bandpass filters (mouth control: filters split audio into bands); card 25 horizontal/vertical rate ramp generators; card 31 dual multiplier (null points, output offsets).
- Animation Aid hardware (p035-p041): 2 HF oscillators (~90 kHz max), 3 LF oscillators, dual full-wave rectifier (no controls), dual analog multiplier (multiply any function by another or variable gain amp), SIX unity-gain inverting summing amps (3 inputs each), FIVE gain pots (attenuators), FIVE bias pots (+/-15 V range), a 10x10 patch panel with all inputs/outputs, short-circuit protected outputs, and inputs to Scanimate "cherry switch" (cherry switch = Scanimate input patching/bus matrix with gain pots 1-6 and sections/buses, p042-p043). Signal levels: +/-10 V oscillator amplitude (p039); +/-15 V supply (p041).
- Cherry switch buses: "final horiz/vert/depth section N to bus M" - selects which bus modulates each channel's final or initial position per section (p042-p050). Pots 2..6 on cherry switch are gain per bus (p042).
- Initial/final: every control has INITIAL and FINAL values (A/B states); "initial/final" switch on Scanimate sets which is displayed; ramp interpolates between (p037-p038, p047). This is Scanimate's A-B switch concept: "Initial-final-initial operation would be similar to the A-B switch on Scanimate" (p047).
- Commutators (SM-102A, p001, p068-p070): per-section sets of 15 pots (15 knobs concentric, 3 pots x 5? parts list lists 15 var 10k pots + 15 knobs per card), 18 diodes and 15+15 transistors forming switches; SM-102A supplies the section-wise piecewise constants, quantity 5 per assy (one per section) (p064). Section-by-section "commutator" = per-section DC position/size/etc.
- Deflection amplifier SM-122C initial test (p004-p005): +/-36 V and +/-48 V supplies (Variac up to full line); 20 kHz triangle input, +/-2 V in gives +/-10 V out at T9, inverted; limits at +/-10-11 V; yoke current +/-3 A at full voltage with +/-3 V input, limiting around +/-3.5 A; DC levels at test points +/-34 V/+/-18 V; 20 kHz square wave +/-2 A used to trim C10 for minimum yoke settling time; quiescent bias 0.6-0.7 V on output transistors (class AB). => magnetic (yoke) deflection with current-drive/voltage amp, power amp bandwidth set for at least 20 kHz triangle (so >> 15.7 kHz line rate) (p004-p005).
- Slew/bandwidth implied: HF oscillators 90 kHz max; deflection test at 20 kHz.

### Raster segment patch panel (p052-p053) - Blanking controller patch panel: rows labelled AMP 1-16 IN/OUT (summing amplifiers), INV 1-8, GN (gain) 1-10, HOR RMP, VER RMP, SEQ RMP 1-4, COM (commutator) outputs 1-10, comparators, EXT IN 1-1..5-4 (external inputs per vertical segment 1-5 x horizontal 1-4), SEQ INT 1-5, COM A/B/C, PICK CAM SW OUT. Description (p053): 5 sequence ramp outputs, 5 sequential intensity pulses, horizontal and vertical ramp generator outputs, summing amps, voltage comparators, digital inverters, offset/gain controls. Summing amps sum H and V ramps with sequence ramps in combos -> comparators -> digital outputs (optionally inverted) -> external inputs for a raster segment. This builds arbitrary wipes (diagonal, circular via summed ramps, etc.) by thresholding a summed ramp: i.e. wipe shape = comparator(H*a + V*b + seq_ramp).

## 4. COLORIZING

- Colorizer purpose: produce an NTSC color representation of a static or dynamic scene produced on a CRT controlled by a Scanimate; "each color is independently selectable and variable"; signals in discrete gray shades drive R,G,B components assigned per shade; exclusive logic for independent selection (p017).
- LEVEL DETECTOR CVS-103B (p018, p021-p022): video from the pickup camera is clamped to ground during blanking, fed to non-inverting inputs of FOUR comparators (IC1-IC4); the inverting side of each comes from a front-panel slider pot (level adjust). As video rises, comparators trip in turn; only ONE output level is on at any time (zero = on, positive = off, active-low); composite blanking gates the first level off during blanking when all five lines go positive (p022). => 4 thresholds -> 5 gray levels (levels 1..5). Includes an amplifier that inverts the "correction signal" going to level adjust pots (R16 Corr Level sets +1 V nominal; R15 Corr Gain) (p022) -- a correction term subtracting from thresholds to compensate shading or beam transition droop.
- COLOR SWITCHES CVS-101B (p022): 5 level lines, one active at a time; each controls bases of three transistors for R, G, B gating; gain of each set by an external color-control slider pot (2.4k emitter resistor) for 1 V output at max gain and 0 V at min (p022). => each of 5 levels has independent R,G,B sliders. Full RGB mix per level, continuous (not palette-limited).
- COLOR MATRIX CVS-100B (p022-p023): added to the Type 140 NTSC test generator; converts R,G,B from color switches to Y, R-Y, B-Y (composite NTSC); Y = resistive sum of R,G,B (R36,R37,R61); -Y added to R and B for R-Y/B-Y; blanking gates the current amplifiers; switch S1 can inhibit Y, R-Y, B-Y. Adjust with Type 528 waveform monitor and Type 520 vector scope using white/red/green/blue/black bars. Black 0 percent, white 100 percent (p023).
- MIX-EFF AMPLIFIER VS-103 (p023-p024): mixes delayed camera video (A) with colorizer Y (B); "Transition" dual pot crossfades (A gain / B gain trims); white clip (R92) clips white level; offset/pedestal from front panel Pedestal control; output returns to color matrix as the new Y. So the colorizer lets you dissolve between the original grayscale picture and the colorized picture, and sets a white clip and pedestal.
- GRAY LEVEL ENCODER (p018-p019): Gray Level Switches CVS-111: four Level Select front-panel switches enable gates (active at 0 V), resistively summed (R1-R10) into composite encoded video = a posterized grayscale. Video amp CVS-112: three dual gated amps with digital A/B select: (1) encoded video vs analog video; (2) invert/non-invert; (3) blanking added. Output goes to the X-Y monitor. Adjust encoder gain for 1 V p-p; blanking level 5 percent pedestal below black (p019) (sketch shows ~5 percent). Encoder and analog gains: 1 V p-p out or 0.8 V p-p at IC1.
  - So the "gray-level encoder" quantizes the camera video to N gray levels to display on the monitor.
- ARTWORK LUMINANCE LEVEL PREP (p012-p015): 2-level: black Kodalith vs clear; 3-level: black, clear, and middle grey "Letrafilm 237", created with a 120-line halftone screen (bipacked line shot) so the screened area reproduces the grey of #237; 4-level adds light grey Letrafilm #173 (two 120-line screened levels); 5-level adds dark grey Letrafilm #177 (three greys) (p012-p015). Rubylith mask in register for composite shot (p013-p014). Assign lighter colors to higher levels, darker to lower levels to minimize fringing; fringing then appears as dark edges next to lighter colors (p013). Artwork spacing: 1/4 inch between "bones" (lettering) in 2-level work (p012). Intermediate grey chosen "for best separation of values, reducing the chance of noise" (p013).
- So: up to 5 luminance levels (black, 3 greys, white) = 5 color slots; practical 2-5.
- Colored sections: "Sections containing 2 colors on a 1 color background" (3 levels) (p013), "3 colors on 1 color background" (4 levels) (p014).
- Thresholds are slider pots (continuous, not fixed numbers); no numeric voltage thresholds given, but video is nominally "1 volt of video" (p012) peak white at the pickup.
- Blanking "5 percent pedestal ratio between black level and blanking" (p019).

## 5. RECORDING / OUTPUT

- Output standard NTSC color via Type 140 NTSC test generator (sync/blanking/burst source), with 50/60 Hz references and SM-144 card "for TV rates" (p001, p017, p021, p084): both 50 Hz and 60 Hz sync supported by Cardinal/CI hardware.
- Scan converter camera (pick-up) reads the X-Y monitor CRT; "X-Y camera" gets horizontal and vertical reset pulses derived from drive pulses (H drive delayed 1.5 us, V delayed 0.2 ms) (p021). Camera's own deflection is reset by those pulses so the camera scan is locked to NTSC timing.
- Frame/shutter references: "shutter bar" and "scan converter bar" positions in frame (p008) imply film (animation stand/camera) shooting of the X-Y monitor with shutter sync (the dark bar is where the shutter/phase falls) plus the TV scan-converter bar. 24 fps frame counting in examples (p043, p048, p050) suggests film-rate computations (24-frame second) even though NTSC is 30 fps.
- Video switching: A/B/C buses, key, lap dissolve, wipes (p029).
- Waveform/vector monitors: Type 528 and 520 used for adjust (p023).
- Video levels: 1 V p-p composite/gray video (p012, p019); blanking 5 percent below black (p019); NTSC 100 percent white, 0 percent black (p023).

## Design hints distilled for Rasterwarp
1. Time/transition model: N (<=5) sections; each has independent INITIAL/FINAL state; up to 5 timed ramps (rate + start frame offset, 3-digit frame thumbwheel 0-999, optional x2); linear/sine (ease) shapes; ramp-reset is instantaneous; A-B-A built from two ramps via subtraction; frame times based on 24 fps units (72 frames = 3 s).
2. Raster: horizontal-line-quantized sections (line-count thumbwheels, 2-line blanking gap between sections), HF line-locked ripple up to ~90 kHz (several cycles per line), LF animation oscillators phase-locked to frame or sequence, top/bottom polarity choice, sine/cosine start phase, triangle or sine waveform.
3. Rotation: sin/cos 20 V p-p, matrix multiply, pivot at "axis"; imperfect nulling allows slight axis wander.
4. Colorizer: 5 levels via 4 comparators (one-hot), per-level RGB sliders, optional dissolve between mono and color (Transition), white clip, pedestal; edge fringing at vertical edges from finite transition time; light colors on high levels.
5. Output: NTSC, 5% blanking pedestal, 1 V video.
