## 1. ANIMATION OVER TIME / TRANSITIONS
- Timebase is the frame; examples treat 24 counts = 1 second (film), e.g. 23-frame counter reset for a once/second jump, start times 072/144/216 = 3/6/9 s (p203, p208). Video itself is NTSC (p254: vert drive 59.94 Hz /2 = 30 Hz frame).
- Frame counter (AM-103A/105C): 3 decade counters (units/tens/hundreds), thumbwheel compare 000-999 frames; X1/off/X2 switch: X2 doubles range (about 40 s to over 80 s); count input labeled "frame or 1/2 frame" (p197, p205, p226, p215).
- Sequence Ramp Generators: FIVE ramp channels (AM-104B, 3 per card). Each has RATE pot, manual/off/auto switch, linear (triangle) or SINE-shaped (S-curve ease in/out) select (p197-198, p215, p227). A "reset rate" pot sets how fast ramp returns. Ramp 1 starts from the Scanimate "initial/final" switch; ramps 2-5 start when frame count equals their 3-digit thumbwheel "start N"; any order, independent rates; returning to final resets ramps and counters (p197, p205).
- Initial/Final = A/B preset toggle: image moves between "initial" and "final" setups; ramps are summed to animate between (p205-206). Recipe: ramp up 1 s, hold, ramp back (start 2 = 096 gives 4 s) with two ramps and two summing amps (p205-206).
- Ramp outputs patch to cherry-switch buses to drive size/depth/position; inversion via a summing amp reverses direction; setting pots interact (changing one final changes the others) (p206-209). Same ramp into H and V = 45 degree motion (p209).
- Sequential Intensity Generator (AM-106C): 2-5 sections, one lit at a time, others blanked; frames per section by 2-digit thumbwheel (X1 = 1-99, X10 = 10-990); start/stop switch; loops continuously (p196, p203). Used to blink/jump-cut between positions (p203-204).
- Oscillators double as ramps: LF osc "frame/sequence" lock and "top/bottom" switches; "slow reset" mode makes the osc a sine-shaped ramp generator (p195, p199).
- Phase locking: HF osc locked to horizontal reset (per scanline); LF oscs locked to frame or sequence start; sine/cosine start switch begins the waveform at zero or at a peak (p198-199). AM-113A programmed phase lock: 12-position switch picks lock every N (2-13) counts; FIX vs PRG per oscillator (p236).
- Colorizer transition: VS-103A mix/effects amp = A/B video crossfade (dissolve) with TRANSITION pot on front panel, plus white clip and pedestal (p265-266). Background level buttons latch only at vertical drive, i.e. frame boundaries (p255).
- Mouth sync: audio -> bandpass filters (300 Hz; 1200/2400 Hz; 530/810 Hz) -> rectifier -> limiter -> control voltages for upper lip, lower lip, mouth width (p195, p202, p215, p220-222, p233).

## 2. RASTER / SCANLINES
- TV rates: horizontal 15,750 Hz, vertical 59.94 Hz (typed 59.994), frame 30 Hz; colorizer PLL 567 kHz = 36 x H; 113.4 kHz = 567k/5 (p254). Scan-converter camera blanking: H ~9.5 us (variable), V ~0.9 ms; H reset pulse 20 us, H clamp 6 us; composite blanking 11 us; V delay 0.2 ms, V reset 0.55 ms (p262).
- HF oscillators "approx 90 kHz max" lock to HORIZONTAL line so raster bending is line-synchronous and stationary; they "bend or shape the raster" (p198, p209, p224).
- Raster comes from a vidicon scan-converter camera: 1-inch vidicon, magnetic deflection with yoke drivers; controls linearity, damping, skew, offset (centering), X/Y pincushion; electrostatic + magnetic focus; beam current pot; target voltage (p185-189). Dual Ramp Gen SM-113D gives X/Y ramps with size pots and resets (p185). Camera blanks itself if sweep missing (protection) (p189).
- Blanking controller divides raster by line number (vertical bands 1-5, thumbwheel line count 0-999) and 4 horizontal windows per band via one-shots (9602, 1000-2000 pF timing, microsecond scale, pot adjustable) = up to 20 rectangular masks; horizontal windows start at left edge and chain (p210-211, p237, p239-242).
- No explicit line-count / spot-size / interlace specs found in these pages; bandwidth hints: 3.58 MHz filter, 400 ns delay lines (p253, p256, p260).

## 3. DEFLECTION / SIGNAL GENERATORS
- Animation Controller functions (p194-195): 2 HF osc, 3 LF osc (outputs B1-B5), 2 full-wave rectifiers, 2 multipliers, 6 summing amps (3 in each, unity inverting), 5 gain pots, 5 bias pots (+-15 V), 10x10 patch panel carrying H/V ramps, mouth outputs, sequence ramps D1-D5, intensity pulses C1-C5, cherry-switch buses (p217).
- Oscillator architecture (AM-102D/111): triangle integrator core, frequency from control voltage (FREQ pot or external), comparators flip direction; sine made by diode bridge with SINE SHAPE ADJ pot; amplitude via MC1595L multiplier with AMPLITUDE and FUNCTION inputs (so amplitude can be another voltage); outputs triangle, ramp, sine, plus/minus (p224, p234). Osc 3/4 sine-cosine pair: osc 4 is 90-degree slave of osc 3 (AM-112A), for circles (p199, p235). LF osc has fast/slow, top/bottom reset, cos/sin start.
- Signal ranges: patching +-15 V; amplitude pots about +10 V max (p198, p201).
- Mouth recipe: upper and lower lip oscillators each multiplied by lip control voltage, set to just under one cycle of bend, zero crossings at lip corners; raster sections via cherry switch (p202).
- Blanking panel jacks: rotation control, commutator, pickup camera switch (p238). Wipes: sum H ramp + V ramp + sequence ramp -> comparator -> blanking gives diagonal/shaped wipes (p210-211, p238).

## 4. COLORIZING
- FIVE gray levels from FOUR comparators (NE526A; later CA3046/3054 arrays); thresholds LEVEL 1-2, 2-3, 3-4, 4-5 set by four 1K pots (CVS-123A, between +5 and +10 V); video clamped each line to 0-1 V; composite blanking forces blank; a shading CORRECTION input can be added (p251, p257).
- Each level has independent R, G, B amplitude pots (15 pots, CVS-106B) -> color switches -> R,G,B (1 Vp-p, 75 ohm) -> Y, R-Y, B-Y matrix (CVS-100D, Y gain, R-Y/B-Y gain+balance, 250 ns Y delay) -> modified Tektronix 140 NTSC generator (p247-250, p252).
- Later design: per-channel color comparators CVS-136 (J6-J8) fed by "high video"/"low video" paths; weights ~.59/.30/.11 scribbled (p267, p259-260).
- Background key: pick any of 5 levels (push buttons 1-5 with lamps) as key, EXT/INT; key delayed 800 ns (two 400 ns lines) to match video path; video gate swaps background vs colorized (p181, p253, p255, p258, p261). "Jumper for Scanimate, 2.7K for CAESAR" on color switches (p250).
- Color is hard-banded by brightness; edge softness only from video bandwidth / 3.58 MHz filter (p256).

## 5. RECORDING / OUTPUT
- NTSC: sync lock to 15.75 kHz / 59.94 Hz, burst flag, 3.58 MHz subcarrier, modified Tektronix 140 NTSC signal generator accepting R,G,B (p247, p254, p264). Chain adds switcher (10 inputs, program/preview), waveform monitor, B&W monitor, color monitor (p264). Scan-converter camera video out -> colorizer -> composite.
- 24-count-per-second timing in animation examples suggests film/frame-based use (p203).

## 6. OTHER / AUTHENTICITY
- Dates 1970-1974; Computer Image Corp, Denver (2162 S. Jason St, later 2475 W. 2nd Ave). Supplies +-15, +-5, +-36, +-48 V (Sola), camera HV +800/+300/-100 V (p184, p190, p246).
- Handwritten notes: shading correction (p251); NTSC sync gen note "short lived stupid idea ... cable automation" (p263).
- Imperfections: interacting pots, camera centering/linearity/skew/pincushion adjustments, sine shaping is a diode approximation (adj pot), 1% parts in oscillators.
- Terms: cherry switch, initial/final, sections, commutator, depth (= size), final horiz/vert, buses, sequential intensity, raster segment blanking, scan converter.
